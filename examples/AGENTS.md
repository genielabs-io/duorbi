# Optional Duorbi collaboration instructions

Merge this snippet into your existing instructions; it is not a replacement for project guidance.

- Requests to ask, discuss with, or seek a review from Antigravity authorize scoped delegation to the `antigravity_a2a` role through Duorbi. Codex remains the lead and verifies the response before making its final judgment.
- In Korean, “제미나이”, “제미니”, “Gemini” and “gemini” may be used as collaboration nicknames for this Antigravity role. A product question or quoted name alone does not trigger delegation. A specifically requested different product/API takes precedence.
- Use the installed `duorbi` executable and pass the current conversation's actual absolute project path as --project on every command. The Duorbi checkout is not automatically the target project. If the custom role is unavailable, read its locally installed instructions and call the same CLI directly.
- Resume follow-up turns using their known saved context_id. After restart, inspect `duorbi sessions --project PATH`; use --continue for the intended latest conversation or --context for a specific record. Clarify ambiguous history. Use --new for independent assignments. Never invent IDs, mix projects, or silently start a new conversation when resume fails.
- The default scope is text analysis, design discussion and review. This does not authorize approval bypass, arbitrary edits, credential access or external messages. Report failed calls honestly; never attribute a locally generated answer to Antigravity.
