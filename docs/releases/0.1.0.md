# Duorbi 0.1.0

First tagged release of Duorbi: local A2A collaboration between Codex and Antigravity, with continuing conversations scoped to each project.

## Included

- A `duorbi` CLI backed by the installed Antigravity `agy` CLI in plan mode.
- Persistent A2A/agy conversation IDs with explicit new, continue and selected-context requests.
- Portable user-state directories, strict resume checks and per-context process locks.
- English/Korean setup documentation, Codex role examples and the Duorbi icon.
- A locked dependency set, fake-CLI HTTP restart tests and clean-wheel checks.

## Installation

Requires Python 3.13+, uv and an authenticated Antigravity CLI on `PATH`.

Download the attached wheel, then install it from its download directory:

```sh
uv tool install --python 3.13 ./duorbi-0.1.0-py3-none-any.whl
duorbi --version
```

Source installation is documented in [README](https://github.com/genielabs-io/duorbi/blob/v0.1.0/README.md) and [한국어 안내](https://github.com/genielabs-io/duorbi/blob/v0.1.0/README.ko.md). This is a GitHub release; no PyPI publication is implied.

## Verification and review

The release is checked with the full fake-CLI regression suite, clean installation outside the source checkout, source/archive inspection and macOS Python 3.13/3.14 CI on the release commit. Public source/history, commit metadata, icon provenance and machine-path dependence were reviewed again; see the [review report](https://github.com/genielabs-io/duorbi/blob/v0.1.0/docs/release-review-0.1.0.md).

Attached assets: wheel, source distribution and `SHA256SUMS.txt`.

## Compatibility

macOS preview. Linux execution and native Windows support are not claimed. Conversation recovery requires both the local ID store and Antigravity's retained history; interrupted tasks and pending approvals are not restored. See the README for the local trust boundary and timeout behavior.
