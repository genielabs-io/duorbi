# Duorbi 0.1.0 — withdrawn release

Historical notes for the first tagged release of Duorbi: local A2A collaboration between Codex and Antigravity, with continuing conversations scoped to each project. The GitHub release, its assets and the tag were removed on 2026-10-17.

## Included

- A `duorbi` CLI backed by the installed Antigravity `agy` CLI in plan mode.
- Persistent A2A/agy conversation IDs with explicit new, continue and selected-context requests.
- Portable user-state directories, strict resume checks and per-context process locks.
- English/Korean setup documentation, Codex role examples and the Duorbi icon.
- A locked dependency set, fake-CLI HTTP restart tests and clean-wheel checks.

## Installation

Install from the current `main` branch using [INSTALL.md](../../INSTALL.md), [README](../../README.md) or [한국어 안내](../../README.ko.md). The withdrawn release's download assets are no longer available. Duorbi has not been published to PyPI.

## Verification and review

Before withdrawal, the release was checked with the full fake-CLI regression suite, clean installation outside the source checkout, source/archive inspection and macOS Python 3.13/3.14 CI on the release commit. Public source/history, commit metadata, icon provenance and machine-path dependence were reviewed again; see the historical [review report](../release-review-0.1.0.md).

## Compatibility

macOS preview. Linux execution and native Windows support are not claimed. Conversation recovery requires both the local ID store and Antigravity's retained history; interrupted tasks and pending approvals are not restored. See the README for the local trust boundary and timeout behavior.
