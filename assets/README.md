# Duorbi icon

`duorbi-icon.png` is the selected white-background Duorbi icon, created for this project using image generation. Two connected geometric modules represent collaborating agents. The palette references Codex's lavender/blue app colors and the colors in Antigravity's public icon; the symbol is Duorbi's own artwork.

The artwork is included under the project's MIT license. Product names identify compatibility; Duorbi is an independent project.
